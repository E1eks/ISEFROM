# ROM 失败案例日志 #02 —— 无认证的误差预算会"撒谎"（η < 1）

> 日期：2026-09-12 ｜ 记录人：同学 B
> 算例：电池包 2D 热管理（`battery_2d`），4 组 LHS 快照（seed=7）
> 触发：任务 #26 误差预算仪表盘首次端到端运行

## 现象

查询点 `k_cell=2.0, h=1500, q_gen=1.2e5`（2C 工况），r=3：

| 量 | 值 | 含义 |
|----|----|------|
| E_proj（基截断，Eckart-Young） | 7.87e-03 | 已认证 |
| E_time（Richardson 外推） | 2.05e-04 | 已认证 |
| E_aff | 0 | 已证 |
| **已认证总上界** | **8.07e-03** | — |
| **真实误差（全阶对照）** | **1.96e-02** | — |
| **effectivity η = 上界/真实** | **0.41** | **< 1，上界失效！** |

## 分析

η < 1 不是实现 bug，而是**结构性缺口**：

- E_proj 只度量"基对**训练快照集**的截断误差"（Eckart-Young 保证）
- 查询点是**未见过的新参数**，其解包含基从未见过的成分——这部分误差属于 E_param（参数外推），当前只有无认证残差指示器 `||(I-VVᵀ)r||`，未计入总上界
- 因此总上界漏掉了主导组分 → 给出 0.8% 的"虚假安全感"，而真实误差接近 2%

权衡曲线（r=1..6）提供了旁证：真实误差在 r≤5 时卡在 2~4% 平台降不动——**加模态无法消除参数误差**，直到 r=6 基碰巧覆盖了该成分才收敛。

## 教训与行动

1. **误差预算证书必须区分"已认证"与"指示器"**。证书模板已把无认证残差标注为 indicator 且不并入 total_bound（`src/rom/budget.py`）。
2. **这是任务 #14（认证后验误差界 Δ=‖r‖/β_LB）必要性的最强实证**：只有带稳定性常数下界的残差界才能兜住参数外推误差。已更新 A 的备忘 §6。
3. **η < 1 本身就是自检器**（memo §2）：调试期发现 η<1 时，先怀疑界缺组分，再怀疑实现。本次属于前者。
4. 答辩素材：bound vs true error 一张图讲清"为什么 ROM 需要认证误差界"——比任何理论说教都直接。
